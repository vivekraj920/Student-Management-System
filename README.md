# Student-Management-System
A desktop-based Student Management System developed using Core Java and Swing. The application allows users to manage student records efficiently through a user-friendly interface. It includes features such as user authentication, adding, updating, deleting, and viewing student details, along with file-based data storage.  
## Project Structure
The main project files are inside the `sms` folder.

## How to Run
1. Open the `sms` folder in VS Code
2. Navigate to `src`
3. Run `Main.java`
